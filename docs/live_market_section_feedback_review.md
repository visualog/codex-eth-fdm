# 실시간 시장 섹션 피드백 검토

작성일: 2026-05-31

## 배경

실시간 시장 섹션은 ETH/USDT의 현재 가격, 24시간 변화율, 거래대금, 고가/저가, 최근 60분 가격 흐름을 보여준다.

현재 대시보드 사용자는 트레이딩 경험이 많은 사용자라기보다, 대시보드 정보를 보고도 "무엇을 봐야 하는지", "차트가 무엇을 말하는지"를 먼저 이해해야 하는 초보 사용자에 가깝다. 따라서 실시간 시장 섹션은 전문적인 시장 데이터 표시보다 쉬운 해석 보조가 더 중요하다.

## 사용자 피드백 요약

### 1. 정보 구조와 레이블

- `60분 종가`와 `60 1분 종가`는 일반 사용자에게 의미 차이가 명확하지 않다.
- `24시간 호가 거래대금`은 초보자가 이해하기 어렵다.
- 권장 표현:
  - `60분 종가` -> `최근 1시간 가격`
  - `1분 종가` -> `1분 단위 가격 60개` 또는 `1분봉 60개`
  - `24시간 호가 거래대금` -> `24시간 거래대금`

### 2. 시각적 계층 구조

- 좌측 현재가와 우측 통계 카드가 비슷한 시각적 비중을 가져 시선이 분산될 수 있다.
- 그래프는 최근 60분 기준이고 통계 카드는 24시간 기준인데, 이 차이가 화면에서 바로 드러나지 않는다.
- 권장 개선:
  - 메인 현재가 영역을 조금 더 강조한다.
  - 우측 카드의 제목과 값 사이에 시각적 계층을 더 만든다.
  - `그래프: 최근 60분 / 통계: 최근 24시간` 같은 시간 범위 라벨을 추가한다.

### 3. 상호작용과 피드백

- 그래프에 x축 시간 라벨이 없어 "언제부터 언제까지"의 흐름인지 추정해야 한다.
- 호버했을 때 특정 시점의 가격을 볼 수 있는지 명확하지 않다.
- 권장 개선:
  - x축에 시작, 중간, 끝 시간 라벨을 표시한다.
  - 호버 시 `시각 + 가격` 툴팁과 세로 가이드라인을 표시한다.
  - 모바일에서는 long-press 기준 동작을 정의한다.

### 4. 카피와 설명 텍스트

- 소스 안내 문장에 데이터 출처, 갱신 주기, 펀더멘털 데이터의 성격이 한 줄에 섞여 있다.
- 권장 표현:

```text
데이터 소스: Binance 공개 REST API
가격 정보는 15초마다 갱신됩니다.
펀더멘털 지표는 각 데이터 소스의 제공 주기에 따라 갱신됩니다.
```

### 5. 용어 레벨

- `실시간 시장`, `24시간`, `거래대금`, `종가`, `펀더멘털` 같은 용어는 초보자에게 장벽이 될 수 있다.
- 섹션 단위 정보 아이콘뿐 아니라, 주요 용어 단위의 작은 설명도 추가하면 이해 난이도를 낮출 수 있다.

## 검토 의견

피드백의 방향은 타당하다. 특히 현재 사용자가 초보자라는 전제를 두면, 단순히 데이터를 많이 보여주는 것보다 "이 숫자를 어떻게 읽어야 하는지"를 함께 제공하는 것이 중요하다.

### 바로 반영할 가치가 높은 항목

1. `24시간 호가 거래대금`을 `24시간 거래대금`으로 바꾼다.
2. `60분 종가`를 `최근 1시간 가격`으로 바꾼다.
3. `1분 종가`를 `1분 단위 가격 60개` 또는 `1분봉 60개`로 바꾼다.
4. 그래프와 통계 카드의 시간 범위를 명시한다.
5. 소스 안내 문장을 3줄로 분리한다.

이 변경은 데이터 로직을 건드리지 않고도 사용자 이해도를 바로 높일 수 있다.

### 설계 판단이 필요한 항목

`24시간 고가/저가 기준선을 최근 60분 그래프에 직접 표시하는 제안`은 신중해야 한다.

이유:

- 24시간 고가/저가가 최근 60분 가격 범위와 너무 멀면 그래프가 눌려 보일 수 있다.
- 기준선이 차트 밖에 있거나 너무 멀리 있으면 초보자에게 더 혼란스러울 수 있다.

대안:

- 60분 그래프에는 시간 흐름을 선명하게 보여준다.
- 별도 작은 바 형태로 `현재가가 24시간 범위에서 어디쯤인지`를 표시한다.

예:

```text
24시간 범위: 저가 ---------------- 현재가 -------- 고가
```

이 방식이 초보자에게 더 직관적이다.

## 권장 우선순위

### P1: 즉시 개선

- 어려운 레이블을 쉬운 말로 교체한다.
- 그래프와 통계의 시간 범위를 명시한다.
- 실시간 시장 정보 아이콘의 설명 문구도 새 용어에 맞춘다.

### P2: 해석 보조 강화

- 소스 안내 문장을 여러 줄로 나눈다.
- x축에 시작, 중간, 끝 시간 라벨을 추가한다.
- 현재가 영역과 우측 통계 카드의 시각적 계층을 조정한다.

### P3: 상호작용 고도화

- 그래프 호버 시 시각과 가격 툴팁을 표시한다.
- 세로 가이드라인을 추가한다.
- 모바일 long-press 동작을 정의한다.
- 주요 용어별 작은 툴팁을 추가한다.

## 권장 카피

### 섹션 타이틀

- 기존: `실시간 시장`
- 유지 가능. 다만 정보 아이콘 설명에서 "지금 ETH 가격 분위기를 보는 곳"이라고 풀어주는 것이 좋다.

### 가격 카드

- `24시간 호가 거래대금` -> `24시간 거래대금`
- `24시간 고가` -> 유지
- `24시간 저가` -> 유지
- `최근 갱신` -> 유지

### 차트

- `60분 종가` -> `최근 1시간 가격`
- `1분 종가` -> `1분 단위 가격 60개`
- 보조 라벨: `그래프: 최근 60분`

### 안내 문장

```text
데이터 소스: Binance 공개 REST API
가격 정보는 15초마다 갱신됩니다.
펀더멘털 지표는 각 데이터 소스의 제공 주기에 따라 갱신됩니다.
```

## 결론

이 피드백은 단순한 표현 수정이 아니라, 초보 사용자가 실시간 시장 데이터를 오해하지 않도록 만드는 안전장치에 가깝다.

대시보드의 목표가 "수익을 실현화하는 판단 도구"라면 실시간 시장 섹션은 다음 역할을 해야 한다.

- 지금 가격이 위로 가는지 아래로 가는지 빠르게 보여준다.
- 단기 가격 흐름과 24시간 통계를 혼동하지 않게 한다.
- 사용자가 거래대금, 고가, 저가, 변동률을 어떻게 읽어야 하는지 알려준다.
- 단기 가격만 보고 매수/매도하지 않도록 아래 의사결정 대시보드와 연결한다.

따라서 다음 구현 단계에서는 P1 항목부터 반영하는 것이 적절하다.

## 구현 완료 내역

완료일: 2026-05-31

반영 파일: `ethereum_fundamentals_dashboard/working_dashboard.html`

### 완료된 P1 항목

- `24시간 호가 거래대금`을 `24시간 거래대금`으로 교체했다.
- `60분 종가`를 `최근 1시간 가격`으로 교체했다.
- 차트 보조 라벨을 `1분봉 60개`로 정리했다.
- 통계 카드 묶음에 `통계: 최근 24시간` 라벨을 추가했다.
- 차트 영역에 `그래프: 최근 60분` 라벨을 추가했다.
- 실시간 시장 정보 아이콘 설명을 새 구조에 맞게 수정했다.

### 완료된 P2 항목

- 소스 안내 문장을 3줄로 분리하고, 펀더멘털 지표가 실시간 연동이 아닌 것처럼 오해되지 않도록 표현을 수정했다.
  - `데이터 소스: Binance 공개 REST API`
  - `가격 정보는 15초마다 갱신됩니다.`
  - `펀더멘털 지표는 각 데이터 소스의 제공 주기에 따라 갱신됩니다.`
- 3줄 안내문은 3열 중 가운데 통계 열 안이 아니라, 실시간 시장 섹션 전체에 적용되는 설명이므로 3열 아래 전체 폭 영역으로 이동했다.
- 최근 1시간 차트에 시작, 중간, 끝 시간 라벨을 추가했다.
- 현재가 영역을 시각적으로 더 강조하고, 우측 통계 카드의 값 비중을 낮춰 시선 경쟁을 줄였다.
- 최근 60분 차트와 24시간 통계의 기준 시간이 다르다는 점을 화면에서 분리해 보이도록 했다.

### 완료된 P3 항목

- 차트 포인트에 hover/focus/active 상태를 추가했다.
- 차트 hover 시 세로 가이드라인, 해당 시점, 해당 가격 툴팁이 표시되도록 했다.
- 키보드 포커스 접근을 위해 차트 hit area에 `tabindex="0"`와 `aria-label`을 추가했다.
- 모바일 long-press에 대응할 수 있도록 `active` 상태에서도 툴팁이 표시되게 했다.
- 24시간 고가/저가 기준선을 60분 차트에 직접 넣는 대신, 별도의 `24시간 범위에서 현재가 위치` 바를 추가했다. 이는 차트가 눌려 보이거나 시간 범위가 섞이는 문제를 피하기 위한 대안이다.
