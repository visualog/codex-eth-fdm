# 의사결정 대시보드 / 수익 실현 패널 개선 정리

작성 시각: 2026-05-31 17:41 KST

## 검토 배경

실시간 시장 섹션은 현재가와 1시간 차트를 읽는 영역이고, 의사결정 대시보드와 수익 실현 패널은 사용자가 실제 행동 후보를 판단하는 영역이다. 따라서 이 영역은 시각적 완성도보다 다음 조건이 더 중요하다.

- 현재 결론이 어떤 데이터 근거에서 나왔는지 바로 이해되어야 한다.
- `신규 진입 검토`와 `기존 포지션 관리`가 섞여 보이면 안 된다.
- 신뢰도, 익절가, trailing stop 같은 표현이 확정 수익이나 투자 조언처럼 읽히면 안 된다.
- 진입가, 로컬 고점, 리스크 한도처럼 사용자 입력에 의존하는 값은 상태가 바뀔 때 정확히 초기화되어야 한다.

## 발견한 문제

1. 의사결정 대시보드의 `신뢰도`가 투자 성공 확률처럼 보일 수 있었다.
   - 실제 의미는 확률이 아니라 점수 조건의 정렬 강도에 가깝다.
   - 개선 방향: `판단 강도`로 표현을 바꾸고, 보조 문구로 "확률이 아니라 조건 일치도"임을 명시한다.

2. 결론과 근거의 연결이 약했다.
   - `No Edge`, `Confirmed Strength` 같은 국면은 표시되지만, 초보자는 왜 그 결론인지 바로 알기 어렵다.
   - 개선 방향: 의사결정 패널에 짧은 해석 문구를 추가하고, 근거/리스크 목록은 상위 항목만 보여준다.

3. 수익 실현 패널이 신규 진입과 기존 포지션 관리를 혼동시킬 수 있었다.
   - 진입가가 없는데도 시장 국면이 긍정적이면 수익 실현 패널이 행동 후보처럼 보일 수 있었다.
   - 개선 방향: 진입가가 없으면 제목을 `진입가 입력 필요`로 고정하고, 이 패널은 포지션 관리용임을 설명한다.

4. trailing stop의 기준 고점 상태 관리가 위험했다.
   - 진입가가 없을 때도 `localHigh`가 갱신될 수 있었다.
   - 진입가를 바꿔도 이전 포지션의 고점이 남아 trailing stop 계산에 섞일 수 있었다.
   - 개선 방향: 진입가가 없으면 고점을 초기화하고, 진입가 변경 시 이전 고점을 초기화한다.

5. 포지션 크기 입력이 실제 손실 한도와 연결되어 보이지 않았다.
   - `최대 비중 25%`만 보면 사용자는 그 비중이 계좌 기준으로 어느 정도 위험인지 알기 어렵다.
   - 개선 방향: 전략 모드의 무효화 폭과 최대 비중을 곱해 `계좌 리스크`를 표시한다.

## 적용 계획

1. 의사결정 패널
   - `신뢰도` 라벨을 `판단 강도`로 변경한다.
   - 결론 아래에 `확률이 아니라 조건 일치도`라는 보조 설명을 추가한다.
   - 국면 key를 내부 값으로 유지해 한/영 문구 변경에 영향받지 않게 한다.

2. 수익 실현 패널
   - 진입가 없음: `진입가 입력 필요` 상태를 명확히 표시한다.
   - 진입가 있음: 기존 포지션 관리 기준만 계산한다.
   - 진입가 변경 시 localHigh를 초기화한다.
   - 진입가 없음 상태에서 localHigh가 남아 있으면 제거한다.

3. 리스크 표시
   - `비중 제한`을 `최대 비중`으로 명확히 한다.
   - `계좌 리스크`를 추가해 최대 비중과 무효화 폭이 결합된 손실 한도를 보여준다.
   - 예: 최대 비중 25%, 무효화 폭 10%이면 계좌 기준 약 2.50% 리스크.

4. 검증
   - JS 문법 검사를 통과해야 한다.
   - 진입가 없음 상태에서 trailing stop과 localHigh가 비어 있어야 한다.
   - 진입가 있음 상태에서 localHigh, trailing stop, 계좌 리스크가 계산되어야 한다.
   - 국면 판단은 표시 문구가 아닌 내부 key로 비교되어야 한다.
