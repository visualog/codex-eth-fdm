# UX/UI RAG 레퍼런스와 다음 개선 계획

작성일: 2026-05-31

## 목적

이 문서는 이더리움 펀더멘털 대시보드의 UX/UI 판단을 돕기 위해 사용할 로컬 스킬과 외부 레퍼런스를 정리하고, 다음 개선 작업의 실행 계획을 정의한다.

현재 핵심 문제는 단순한 스타일 문제가 아니라 다음 질문에 가깝다.

- 초보 사용자가 무엇을 먼저 봐야 하는가?
- 실시간 가격, 24시간 통계, 펀더멘털 지표를 어떻게 구분해야 하는가?
- 차트는 요약 카드 안에 작게 넣을 정보인가, 별도 분석 영역으로 키워야 하는가?
- 수익 판단에 필요한 정보와 데이터 상태 정보를 어떻게 분리해야 하는가?

## 사용할 로컬 스킬

### 1. critique

용도: UX 관점의 판단 기준을 잡는다.

적용 범위:

- 정보 구조
- 시각적 계층
- 초보자의 인지 부하
- 섹션별 우선순위
- 사용자가 다음 행동을 알 수 있는지

현재 대시보드에서는 `실시간 시장` 섹션의 3열 구조, 차트 위치, 통계 카드 구성, 의사결정 대시보드와의 연결성을 평가하는 데 가장 직접적으로 쓴다.

### 2. arrange

용도: 레이아웃, 간격, 배치, 시각적 리듬을 조정한다.

적용 범위:

- 3열 구조 재배치
- 그래프를 전체 폭으로 내릴지 판단
- 카드 간격과 정렬
- 화면 폭별 레이아웃
- 요약 영역과 분석 영역 분리

현재 대시보드에서는 우측 `최근 1시간 가격` 그래프가 영역에 비해 작게 보이는 문제를 해결할 때 사용한다.

### 3. clarify

용도: 초보자가 이해하기 쉬운 문구와 라벨로 바꾼다.

적용 범위:

- `종가`, `거래대금`, `펀더멘털`, `소스별 주기` 같은 용어 설명
- 정보 아이콘 설명 문구
- 차트/통계 해석 안내
- 오해를 부르는 데이터 갱신 문구 제거

현재 대시보드에서는 수익 판단용 문구와 차트 해석 문구를 다듬는 데 중요하다.

### 4. harden

용도: 실제 사용 환경에서 깨지지 않도록 견고성을 높인다.

적용 범위:

- 한/영 토글 후 레이아웃 유지
- 긴 숫자와 긴 문구 overflow 방지
- 모바일 폭에서 카드와 차트가 겹치지 않게 조정
- 데이터 실패/지연 상태 표시
- 접근성 속성 확인

### 5. polish

용도: 최종 시각 품질을 다듬는다.

적용 범위:

- 미세 간격
- 글자 굵기
- 대비
- 카드 높이 균형
- 차트 라벨과 보조 문구 정리

## 외부 UX/UI 레퍼런스

### 1. TradingView

참조 링크:

- https://www.tradingview.com/support/solutions/43000747934-time-intervals-a-quick-introduction-and-tips/
- https://www.tradingview.com/support/solutions/43000517005-date-range-drawing-tool/

참고할 점:

- 차트는 시간 범위와 데이터 간격을 명확히 알려준다.
- 사용자가 커서를 움직이면 해당 시점의 시간과 가격을 확인할 수 있다.
- 시간 범위, 캔들/라인 차트, 지표 설정이 차트 상단 도구와 자연스럽게 연결된다.
- 날짜/시간 범위 도구는 선택한 구간의 시간, bar 수, volume 같은 보조 정보를 보여준다.

현재 대시보드에 적용할 점:

- `최근 1시간 가격` 그래프는 작은 보조 그림이 아니라 사용자가 흐름을 읽는 차트로 다뤄야 한다.
- 시간축, 현재가, hover tooltip, vertical guideline은 유지하거나 강화한다.
- 그래프가 3열 중 한 칸에 갇히면 TradingView식 읽기 경험과 거리가 멀다.

### 2. Coinbase Advanced

참조 링크:

- https://help.coinbase.com/en/coinbase/trading-and-funding/advanced-trade/dashboard-overview

참고할 점:

- 실시간 시장 정보, 가격 차트, 오더북, 주문 패널, 거래 내역의 역할을 분리한다.
- 가격 차트는 시간 범위와 차트 타입을 변경할 수 있다.
- x축/y축, 고가/저가/시가/종가 같은 기본 개념을 설명한다.
- 고급 트레이딩 화면이지만 정보 영역의 역할은 명확하다.

현재 대시보드에 적용할 점:

- 시장 수치와 데이터 상태 정보를 같은 카드 그룹에 섞지 않는다.
- `최근 갱신`은 시장 수치 카드가 아니라 데이터 상태/소스 안내 영역에 둔다.
- 가격 차트는 통계 카드 옆의 장식이 아니라, 별도 읽기 영역으로 키우는 것이 낫다.

### 3. DeFiLlama

참조 링크:

- https://defillama.com/

참고할 점:

- TVL, DEX Volume, Fees, Revenue, Stablecoins 같은 지표를 카드/테이블/차트로 분리한다.
- `24h`, `7d`, `1m`처럼 지표의 시간 범위를 명확히 표시한다.
- 핵심 지표와 상세 프로토콜 랭킹을 같은 화면 안에서도 다른 계층으로 보여준다.

현재 대시보드에 적용할 점:

- 펀더멘털 지표는 실시간 가격 차트처럼 보이게 하지 않는다.
- 지표별 시간 범위와 카테고리를 명확히 표시한다.
- 초보 사용자가 볼 수 있도록 각 지표에 "이 숫자가 의미하는 것"을 짧게 붙인다.

### 4. Glassnode Studio

참조 링크:

- https://glassnode.com/products/studio

참고할 점:

- 온체인, 현물, 파생상품 데이터를 하나의 분석 뷰로 묶는다.
- near real-time snapshot, core indicators, curated dashboards처럼 사용자가 시작할 수 있는 구조를 제공한다.
- 전문가용 지표를 그대로 나열하기보다, 관점이 있는 대시보드 묶음으로 제공한다.

현재 대시보드에 적용할 점:

- 초보자용 시작점과 고급 분석 지표를 분리한다.
- 먼저 볼 지표 묶음, 이후 확인할 근거 차트를 나눠야 한다.
- 단일 수치보다 "현재 시장 상태 요약"을 앞에 둔다.

### 5. Token Terminal

참조 링크:

- https://tokenterminal.com/resources/articles/token-terminal-key-metrics-faq

참고할 점:

- 크립토 지표를 재무제표처럼 해석한다.
- Fees, Revenue, TVL 같은 지표가 무엇이고 왜 중요한지 설명한다.
- 펀더멘털 지표를 단순 차트가 아니라 투자 판단 맥락으로 연결한다.

현재 대시보드에 적용할 점:

- 펀더멘털 지표는 "높으면 좋은가?", "낮으면 위험한가?"를 함께 설명해야 한다.
- 지표 탐색 영역은 차트를 보여주는 데서 끝나지 않고, 해석 문구를 포함해야 한다.

## 현재 대시보드에 대한 UX 판단

### 실시간 시장 섹션

현재 구조:

- 왼쪽: 현재가와 24시간 변동률
- 가운데: 24시간 거래대금, 고가, 저가, 변동폭
- 오른쪽: 최근 1시간 가격 그래프
- 하단: 데이터 소스와 갱신 주기

판단:

- 왼쪽과 가운데는 요약 정보로 적합하다.
- 오른쪽 그래프는 현재 3열 중 한 칸에 갇혀 있어, 시간 흐름을 읽기에는 폭이 부족하다.
- 차트가 사용자가 해석해야 하는 정보라면 전체 폭으로 내려야 한다.
- 3열 구조는 요약 정보용으로 유지하고, 차트는 그 아래 별도 행으로 두는 것이 더 적합하다.

권장 구조:

```text
[현재가 / 24h 변동률] [24h 통계 카드] [24h 범위와 데이터 상태]
[최근 1시간 가격 차트 - 전체 폭]
[짧은 데이터 소스 / 갱신 주기 안내]
```

### 펀더멘털 영역

판단:

- DeFiLlama/Glassnode/Token Terminal처럼 지표를 카테고리별로 묶어야 한다.
- 초보 사용자는 차트 자체보다 "이 지표가 말하는 것"이 필요하다.
- Decision Dashboard와 지표 탐색 사이의 연결이 더 강해야 한다.

권장 방향:

- 지표 카드마다 `좋은 신호`, `주의 신호`, `현재 해석`을 붙인다.
- 카테고리별 핵심 지표를 먼저 보여주고, 상세 차트는 다음 단계로 둔다.

## 다음 개선 작업 계획

### 1단계: critique 기준으로 실시간 시장 섹션 재평가

목표:

- 초보 사용자가 상단 섹션에서 무엇을 먼저 봐야 하는지 명확히 한다.

작업:

- 현재 3열의 역할을 재정의한다.
- 그래프가 3열 안에 있어야 하는지, 전체 폭으로 내려야 하는지 최종 판단한다.
- 데이터 상태 문구와 시장 수치가 섞이지 않았는지 점검한다.

완료 기준:

- 섹션 안의 각 영역 역할이 한 문장으로 설명 가능해야 한다.
- 사용자가 현재가, 24시간 통계, 최근 1시간 흐름을 혼동하지 않아야 한다.

### 2단계: arrange 기준으로 레이아웃 재구성

목표:

- 최근 1시간 가격 차트를 읽기 쉬운 크기로 만든다.

작업:

- 상단 3열은 요약 영역으로 유지한다.
- 우측 그래프를 3열 아래 전체 폭 영역으로 이동한다.
- 그래프 높이와 가로폭을 충분히 확보한다.
- 24시간 범위 바는 요약 영역에 남기거나 차트 위 보조 정보로 재배치한다.

완료 기준:

- 데스크톱에서 그래프가 섹션 폭 대부분을 사용해야 한다.
- 모바일에서 요약 정보와 차트가 자연스럽게 세로로 쌓여야 한다.
- 시간 라벨과 hover tooltip이 잘리지 않아야 한다.

### 3단계: clarify 기준으로 문구 정리

목표:

- 초보자가 용어를 몰라도 화면을 읽을 수 있게 한다.

작업:

- `24시간 거래대금`, `24시간 변동폭`, `최근 1시간 가격`, `펀더멘털은 소스별 주기` 문구를 다시 점검한다.
- 정보 아이콘 설명을 새 레이아웃에 맞게 수정한다.
- 차트 아래 또는 위에 짧은 해석 문구를 추가할지 판단한다.

완료 기준:

- 문구가 길어져 공간을 잡아먹지 않아야 한다.
- 오해를 줄이되 화면 밀도는 유지해야 한다.

### 4단계: harden 기준으로 반응형/접근성 점검

목표:

- 실제 화면 폭과 언어 전환에서 깨지지 않게 한다.

작업:

- 데스크톱, 태블릿, 모바일 폭에서 레이아웃 확인
- 한/영 토글 후 텍스트 overflow 확인
- chart hover/focus/active 동작 확인
- 스크린리더용 label 확인

완료 기준:

- 텍스트가 카드 밖으로 나가지 않아야 한다.
- 차트 툴팁이 잘리지 않아야 한다.
- 키보드 focus 상태에서도 의미 있는 정보를 제공해야 한다.

### 5단계: polish 기준으로 최종 마감

목표:

- 실시간 시장 섹션이 대시보드의 첫 화면으로 신뢰감 있게 보이도록 만든다.

작업:

- 카드 간격, 라벨 크기, 선 굵기, 대비 조정
- 차트와 요약 카드 간 시각적 균형 조정
- 불필요한 보조 문구 제거
- 데이터 상태 표시를 더 조용하지만 명확하게 정리

완료 기준:

- 첫눈에 현재가, 24시간 통계, 1시간 흐름이 구분되어야 한다.
- 초보자가 화면 설명 없이도 기본 의미를 파악할 수 있어야 한다.
- 트레이딩 경험자가 보기에도 정보 밀도가 너무 낮아 보이지 않아야 한다.

## 우선 실행안

다음 구현에서는 아래 순서로 진행한다.

1. `최근 1시간 가격` 그래프를 3열 아래 전체 폭으로 이동한다.
2. 상단 3열은 요약 정보만 남긴다.
3. 24시간 범위 바와 데이터 상태 안내 위치를 재정리한다.
4. 차트 tooltip, 시간 라벨, 현재가 표시가 전체 폭 레이아웃에서도 정상 동작하는지 확인한다.
5. 모바일에서 1열로 자연스럽게 쌓이는지 확인한다.

- 차트가 고정 폭처럼 보이지 않도록 실제 차트 컨테이너 폭을 읽어 SVG `viewBox` 폭에 반영했다.
- 데스크톱 차트 높이는 300px, 모바일 차트 높이는 240px로 조정했다.

### 3단계: clarify 기준 문구 정리 완료

- 차트 보조 문구를 `1분봉 60개 · 마우스를 올리면 시각과 가격을 확인할 수 있습니다.`로 정리했다.
- 데이터 소스 안내는 `Binance 가격 15초 갱신 · 펀더멘털은 소스별 주기 · 최근 갱신 ...` 형태의 한 줄 메타 정보로 압축했다.
- 펀더멘털 지표 카드마다 다음 해석 블록을 추가했다.
  - 좋은 신호
  - 주의 신호
  - 현재 해석

### 4단계: harden 기준 점검 완료

- 한/영 토글용 번역 키를 추가했다.
- 모바일 폭에서 실시간 시장 섹션이 1열로 자연스럽게 쌓이도록 유지했다.
- 차트 hover/focus/active 상태와 `aria-label` 기반 포인트 정보를 유지했다.
- 데이터 상태 영역은 `가격 데이터 정상/대기`, `최근 갱신` 정보를 제공하도록 했다.
- 차트 리사이즈 시 다시 렌더링되도록 resize listener를 추가했다.

### 5단계: polish 기준 마감 완료

- 차트와 요약 카드 간 시각적 균형을 조정했다.
- 차트 현재가 기준선을 추가해 마지막 가격 위치를 더 쉽게 읽게 했다.
- 카드 내부 해석 블록은 별도 구분선과 작은 글자 위계로 정리했다.
