# 모바일 거래앱 화면 참고 검토

작성일: 2026-05-31

## 검토 대상

사용자가 첨부한 이미지는 Binance 계열 모바일 종목 상세 화면으로 보인다. 화면에는 `ADA/USDT` 종목명, 현재가, 24시간 고가/저가, 거래량, 시간 범위 버튼, 캔들 차트, 우측 현재가 태그, 수평 기준선 가격 태그가 함께 표시되어 있다.

이미지 자체는 우리 프로젝트 파일로 저장하지 않았다. 이 문서는 첨부 이미지를 보고 추출한 UI/정보 구조와 우리 `Ethereum Fundamentals Dashboard`에 적용할 항목을 기록한다.

## 이미지에서 확인한 정보 구조

- 상단에 자산 페어와 즐겨찾기/알림 같은 빠른 액션이 있다.
- `Price`, `Info`, `Trading Data`, `Audit` 같은 탭으로 정보 종류를 분리한다.
- 현재가가 가장 큰 숫자로 표시된다.
- 24시간 변화율은 현재가 바로 아래에 색상으로 표시된다.
- 24시간 고가, 저가, 거래량은 오른쪽에 압축 배치된다.
- `15m`, `1h`, `4h`, `1D`, `More` 시간 범위 컨트롤이 차트 바로 위에 있다.
- 캔들 차트 오른쪽에는 현재가가 색상 태그로 붙는다.
- 특정 기준가는 수평선과 오른쪽 가격 태그로 표시된다.

## 우리 대시보드에 참고할 항목

### 1. 현재가 중심 상단 요약

이미지는 현재가를 가장 먼저 읽게 만들고, 24시간 변화율과 고가/저가/거래량을 주변에 압축한다. 우리 대시보드는 이미 실시간 시장 섹션과 핵심 지표 스트립을 갖고 있으므로, 현재가 중심 구조는 유지하되 스트립이 보조 요약 역할을 하도록 둔다.

적용 판단: 이미 일부 반영됨. 추가 구조 변경은 보류.

### 2. 시간 범위 버튼

이미지의 `15m / 1h / 4h / 1D` 구조는 우리 차트의 `15분 / 1시간 / 4시간 / 24시간` 컨트롤과 같은 패턴이다.

적용 판단: 이미 반영됨.

### 3. 현재가 오른쪽 태그

이미지에서 가장 직관적인 요소는 차트 오른쪽에 붙은 현재가 태그다. 차트의 마지막 가격이 축 옆에 붙어 있어 사용자가 현재 위치를 빠르게 읽는다.

적용 판단: 우선 적용.

### 4. 수평 기준선 오른쪽 가격 태그

이미지의 흰색 수평선과 오른쪽 `0.2526` 태그는 특정 기준가를 매우 분명하게 만든다. 우리 대시보드의 `24h`, `진입`, `익절`, `리스크` 오버레이도 같은 방식으로 오른쪽 끝에 라벨을 붙이는 것이 더 적합하다.

적용 판단: 우선 적용.

### 5. 탭 구조

`Price / Info / Trading Data / Audit` 탭은 긴 모바일 화면에서 정보 탐색을 쉽게 만든다. 우리 대시보드도 장기적으로 `시장`, `펀더멘털`, `의사결정`, `백테스트`, `저널` 탭 또는 섹션 점프를 둘 수 있다.

적용 판단: 다음 단계 후보. 이번 작업에서는 보류.

### 6. 자산 태그

이미지의 `Layer 1 / Layer 2 / Hot` 태그는 자산 맥락을 빠르게 전달한다. ETH 대시보드에는 `L1`, `Staking`, `DeFi`, `L2`, `Blob demand` 같은 태그가 가능하다.

적용 판단: 다음 단계 후보. 상단 정보가 이미 많으므로 이번 작업에서는 보류.

## 이번 적용 범위

이번 작업에서는 첨부 이미지에서 차트 판독성에 직접 도움이 되는 두 가지를 적용한다.

1. 현재가를 차트 오른쪽 색상 태그로 표시한다.
2. 오버레이 판단선 라벨을 차트 오른쪽 가격축 근처의 태그로 이동한다.

상단 탭 구조와 자산 태그는 화면 정보 구조를 더 크게 바꾸므로 별도 작업으로 남긴다.

## 기대 효과

- 차트에서 현재 가격의 위치가 더 즉시 보인다.
- 진입가, 익절, 손절, 무효화 같은 판단선이 가격축과 직접 연결된다.
- 모바일 거래앱의 장점인 빠른 가격 판독성을 흡수하면서, 우리 대시보드의 펀더멘털/의사결정 구조는 유지한다.
