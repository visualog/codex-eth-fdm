# 실시간 차트 전환 개선 검토

작성일: 2026-05-31

## 질문

실시간 시장 차트에서 시간 범위, 차트 형태, 판단선 오버레이를 클릭했을 때 차트 변화에 트랜지션을 넣는 것이 좋은가? 이 작업에 GSAP 같은 외부 애니메이션 라이브러리가 필요한가?

## 결론

짧은 트랜지션은 적용하는 것이 좋다. 현재 차트는 SVG를 즉시 교체하기 때문에 시간 범위나 차트 형태가 바뀔 때 화면이 갑자기 바뀌는 느낌이 있다. 140-180ms 정도의 fade/slide 전환을 넣으면 사용자가 방금 누른 컨트롤과 차트 변화의 관계를 더 쉽게 이해한다.

다만 GSAP는 이번 범위에는 필요하지 않다. 이 대시보드는 단일 HTML, 무빌드, 무의존성 로컬 실행을 유지하는 것이 중요하다. 현재 요구는 복잡한 path morphing이 아니라 차트 상태 교체의 시각적 완충이므로 CSS transition과 작은 JavaScript class 토글이면 충분하다.

## GSAP가 필요한 경우

GSAP 또는 D3/Web Animations API가 유효한 경우는 다음과 같다.

- 이전 라인 path가 새 path로 부드럽게 morph해야 할 때
- 캔들, 오버레이, 축, 툴팁을 타임라인으로 정교하게 순차 제어할 때
- 여러 차트 패널이 같은 타이밍으로 choreograph되어야 할 때
- 드래그/줌/스크럽 같은 고급 인터랙션을 추가할 때

이번 개선은 이 범위가 아니므로 외부 의존성을 추가하지 않는다.

## 추천 구현

1. 차트 교체 직전에 `.is-transitioning` class를 추가한다.
2. 기존 차트를 `opacity`와 `transform`으로 아주 짧게 낮춘다.
3. SVG를 교체한다.
4. 다음 animation frame에서 `.is-transitioning`을 제거해 새 차트를 자연스럽게 등장시킨다.
5. `prefers-reduced-motion: reduce`에서는 전환을 비활성화한다.

## 적용 범위

- 시간 범위 변경: `15분 / 1시간 / 4시간 / 24시간`
- 차트 형태 변경: `라인 / 범위 / 캔들`
- 판단선 오버레이 변경: `24h / 진입 / 익절 / 리스크`
- 실시간 폴링으로 차트가 갱신될 때도 같은 짧은 전환을 적용하되, 모션은 과하지 않게 유지한다.

## 적용하지 않는 것

- GSAP CDN 추가
- 라인 path morphing
- 캔들 개별 순차 등장
- 축 재계산 애니메이션
- 긴 로딩 애니메이션

## 기대 효과

- 클릭 후 차트 변화가 덜 갑작스럽다.
- 버튼 상태 변화와 차트 상태 변화가 하나의 조작으로 연결되어 보인다.
- 단일 HTML 구조와 로컬 실행 안정성을 유지한다.
- 모션 민감 사용자의 설정을 존중한다.
