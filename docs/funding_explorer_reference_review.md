# HL Funding Explorer 참고 검토

작성일: 2026-05-31

## 검토 대상

사용자가 첨부한 `Capital Flows Research / HL Funding Explorer` 화면은 가격 차트, 펀딩비, 이동평균, Z-score, 롤링 포지션 비용, 기간별 히트맵을 함께 보여주는 파생상품 중심 대시보드다.

우리 `Ethereum Fundamentals Dashboard`는 ETH 펀더멘털, 실시간 현물 시장, 수익 실현 판단 보조를 목표로 한다. 따라서 첨부 화면을 그대로 복제하기보다, 수익 실현 판단에 직접 도움이 되는 정보 구조만 선별 적용한다.

## 첨부 대시보드가 제공하는 정보

- 선택 자산의 가격 흐름
- 펀딩비와 펀딩비 이동평균
- 펀딩비 Z-score와 상단/하단 밴드
- 롱 포지션을 유지할 때의 누적 또는 롤링 비용
- 여러 자산의 기간별 가격 변화 히트맵
- 여러 자산의 기간별 평균 펀딩비 히트맵
- 현재 상태를 빠르게 읽는 상단 요약 지표 스트립

핵심 질문은 단순히 "가격이 오르는가"가 아니라 "그 포지션을 유지하는 비용과 과열도가 감당 가능한가"에 가깝다.

## 우리 대시보드에 바로 참고할 요소

### 1. 상단 핵심 지표 스트립

첨부 화면은 가장 중요한 숫자를 상단에 압축해 현재 상태를 빠르게 읽게 한다. 우리 대시보드도 실시간 시장 섹션에서 `현재가`, `24시간 변화`, `거래대금`, `24시간 범위`, `시장 국면`, `리스크 점수`를 한 줄 요약으로 보여주면 사용자의 첫 판단 속도가 빨라진다.

적용 판단: 우선 적용.

### 2. 차트 오버레이 토글

첨부 화면은 가격 위에 펀딩비, 이동평균, 밴드, 비용 라인을 켜고 끌 수 있다. 우리 차트에는 펀딩비보다 먼저 `24시간 고가/저가`, `기준 진입가`, `1차/2차 익절`, `추적 손절`, `무효화 가격` 같은 실제 보유 판단선을 오버레이하는 편이 더 적합하다.

적용 판단: 우선 적용.

### 3. Z-score / 과열도 개념

펀딩비 Z-score는 "평소보다 얼마나 튀었는가"를 보여준다. 우리 대시보드에는 가격, 거래량, 변동성, ETH/BTC, 펀더멘털 대비 가격 괴리의 과열도를 별도 점수나 카드로 확장할 수 있다.

적용 판단: 다음 단계 후보.

### 4. 기간별 변화 히트맵

첨부 화면의 히트맵은 여러 종목 비교에 강하다. 우리 대시보드는 ETH 중심이므로 동일한 규모의 종목 히트맵은 과하다. 대신 `15분`, `1시간`, `4시간`, `24시간`, `7일`, `30일` 기준으로 가격, 거래량, ETH/BTC, 수수료, TVL, L2 사용량 변화를 압축한 ETH 전용 히트맵은 유용하다.

적용 판단: 다음 단계 후보.

### 5. 파생상품/포지션 비용 섹션

첨부 화면의 핵심은 포지션 유지 비용이다. 우리 대시보드에 넣는다면 실시간 시장 섹션 안이 아니라 별도 `파생상품/포지션 비용` 섹션으로 두는 것이 맞다.

후보 지표:

- ETH perpetual funding rate
- Open interest
- Long/short ratio
- Funding Z-score
- 롱 또는 숏 보유 비용

적용 판단: 데이터 소스와 CORS 검증 후 적용.

## 이번 적용 범위

이번 작업에서는 첨부 화면에서 바로 흡수할 수 있고, 기존 공개 API 구조를 유지하면서 구현 가능한 두 가지를 적용한다.

1. 실시간 시장 섹션에 핵심 지표 스트립 추가
2. 실시간 차트에 판단선 오버레이 토글 추가

펀딩비, 오픈이자, 롱/숏 비율은 새 파생상품 데이터 소스 검증이 필요하므로 이번 작업에서는 문서화만 하고 직접 통합하지 않는다.

## 적용 후 기대 효과

- 사용자가 실시간 시장 섹션에 들어오자마자 현재 시장 상태를 압축해서 읽을 수 있다.
- 가격 차트가 단순 가격선이 아니라 보유 판단선과 함께 읽힌다.
- 수익 실현 패널에서 계산한 진입가, 익절, 손절, 무효화 값이 차트에 연결된다.
- 첨부 대시보드의 장점인 "상태 요약"과 "오버레이 기반 분석"은 흡수하되, 화면이 전문 파생상품 터미널처럼 과밀해지는 것을 피한다.

## 보류 항목

- 펀딩비와 오픈이자 직접 통합
- 여러 자산 비교 히트맵
- 펀딩비 Z-score와 롤링 포지션 비용
- 파생상품 데이터 소스 fallback 설계
